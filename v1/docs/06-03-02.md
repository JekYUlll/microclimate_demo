# 切实可行的路径：v1原型扩展失败的文献支撑解决方案

## 问题的本质重新定位

Turn 85的诊断将失败根因定位为**验证-最终窗口的制度迁移失败（regime transfer failure）**，而非教师缺失或监督头不足。这一诊断在文献中有精确对应：这是一个**离线安全强化学习的分布偏移（distribution shift）问题**，叠加了**约束预算下的策略泛化问题**。现有文献提供了三条独立的、可直接落地的技术路径，分别对应Branch A、Branch B和一个此前未考虑的Branch D（新增）。

---

## 路径一：约束自适应策略切换（对应并强化Branch A）

**文献依据：** Chemingui等人（2025）在AAAI 2025提出的CAPS（Constraint-Adaptive Policy Switching）框架 ([Chemingui et al., 2025](https://arxiv.org/abs/2412.18946))，以及同组的O3SRL后续工作 ([Chemingui et al., 2025b](https://arxiv.org/html/2510.22027))。

**核心机制：** CAPS的关键洞察是：在测试时约束预算未知或动态变化的情况下，不应依赖单一策略，而应在训练阶段预先学习一组覆盖不同奖励-代价权衡的策略集合 $\{\pi^r, \pi^1, \ldots, \pi^{K-2}, \pi^c\}$，其中 $\pi^r$ 最大化奖励（忽略代价），$\pi^c$ 最小化代价（忽略奖励）。在部署时，CAPS通过两步决策：(1) **过滤**：保留所有满足当前累积代价约束的策略所选动作；(2) **选择**：在可行动作中选择奖励Q值最大的动作。其安全保证（Theorem 1）表明，对于任意 $\kappa$-admissible策略，期望总代价以 $\max\{V^c_t(s), \kappa - c_{<t}\} + (T-t)\epsilon$ 为上界，其中 $\epsilon$ 为MDP的最优代价变差。

**对v1的直接映射：** v1的核心问题是：在B=1.20约束下，event-threshold策略在验证窗口表现良好（4/5 seeds正向中心），但在最终窗口出现制度迁移失败（seed52/53验证中心为正但最终边际为负）。CAPS框架提供了一个**无需重新训练**的部署时解决方案：

- 将现有的event-threshold策略视为 $\pi^r$（高奖励、约束激活），将static snow-core策略视为 $\pi^c$（低代价、约束保守）
- 在每个部署起点，根据当前SOC状态和累积代价 $c_{<t}$ 动态切换：若event-threshold的代价Q值预测满足 $Q^c_t(s_t, a_t) + c_{<t} \leq \kappa$，则执行event-threshold动作；否则回退至static
- 这将Branch A的"per-start transfer predictor"从一个**离线预测问题**转化为一个**在线过滤问题**，消除了对验证-最终迁移预测准确性的依赖

**具体实施步骤：**
1. 从现有9个可部署行中提取每个起点的 $(s_t, \text{SOC}_t, c_{<t})$ 状态序列
2. 用event-threshold策略的历史轨迹拟合代价Q函数 $Q^c$（可用简单的蒙特卡洛回报估计，无需重新训练）
3. 在seed41-45的最终窗口上回测：对每个时间步，若 $Q^c_t(s_t, a_t) + c_{<t} > \kappa$，切换至static
4. 统计切换后的FW-MAE，与纯event-threshold和纯static对比

**预期效果：** CAPS在DSRL基准的38个任务上一致优于现有方法，尤其在约束严格（$\kappa$ 较小）时优势显著。对于v1的B=1.20场景，CAPS的过滤机制可以在seed44等制度边界条件下自动回退至static，从而将4/5的成功率提升至更稳定的结果，同时保持seed41/42/43/45的动态优势。

**与Branch A的关系：** Branch A的per-start transfer predictor是一个**离线预测器**（预测哪些起点会成功），而CAPS是一个**在线过滤器**（在每个时间步实时决策是否切换）。两者可以组合：先用Branch A的预测器筛选高置信度起点，再在这些起点上部署CAPS的在线切换机制。

## 路径二：实时预算推断（对应并强化Branch B）

**文献依据：** Lin等人（2023）在ICML 2023提出的TREBI（Trajectory-based REal-time Budget Inference）框架 ([Lin et al., 2023](https://arxiv.org/html/2306.00603v2))。

**核心机制：** TREBI将安全离线RL问题从策略优化视角转化为**轨迹分布优化**视角。其核心定理（Theorem 4.1）表明：若行为策略生成的满足约束的轨迹概率不太小（$\int_{C(\tau) \leq b} p_{\pi_\beta}(\tau) d\tau \geq e^{-\epsilon}$），则最优轨迹分布具有闭合形式：

$$q^*_b(\tau) = \begin{cases} p_{\pi_\beta}(\tau) \exp(\alpha R(\tau)) / Z & \text{if } C(\tau) \leq b \\ 0 & \text{otherwise} \end{cases}$$

即：**将不满足预算约束的轨迹概率置零，对满足约束的轨迹按回报重新加权**。这一操作在推断时可以实时执行，无需针对每个预算值重新训练策略。

**对v1的直接映射：** v1的Branch B（start-conditioned static fallback）本质上是一个粗粒度的轨迹过滤：在验证边际为负的起点上回退至static。TREBI提供了一个更精细的版本：

- 将v1现有的9个可部署行的轨迹数据视为行为策略轨迹集合 $\{(\tau_i, R(\tau_i), C(\tau_i))\}$
- 对于给定预算 $b = 1.20$，直接过滤掉 $C(\tau) > b$ 的轨迹，对剩余轨迹按 $\exp(\alpha R(\tau))$ 重新加权
- 加权后的轨迹分布给出了在预算约束下的最优策略的**轨迹级近似**，可用于指导部署时的动作选择

**具体实施步骤：**
1. 从v1的9个selected deployable rows中提取完整轨迹 $(\tau_i, R_i, C_i)$，其中 $C_i$ 为归一化能量消耗
2. 对每条轨迹计算 $C(\tau_i)$；过滤掉 $C(\tau_i) > 1.20$ 的轨迹
3. 对满足约束的轨迹，计算加权系数 $w_i = \exp(\alpha R_i) / Z$，其中 $\alpha$ 可通过交叉验证选取
4. 用加权轨迹集合训练一个轻量级的条件策略（如决策树或线性模型），输入为 $(s_t, \text{SOC}_t, z_t)$，输出为动作概率
5. 在seed41-45的最终窗口上评估

**与Branch B的关系：** Branch B的start-conditioned fallback是一个**二元决策**（整个起点用dynamic或static），而TREBI是一个**连续加权**（在轨迹级别对动态策略进行预算感知的重新加权）。TREBI的上界是轨迹级oracle（每条轨迹独立选择最优策略），比Branch B的起点级oracle更精细，理论上可以获得更高的FW-MAE改善。

**实施成本评估：** TREBI的核心操作（轨迹过滤+加权）是零训练成本的后处理步骤，可以在现有9个可部署行的数据上直接执行。唯一的计算开销是轻量级条件策略的拟合，与Branch A的logistic regression/gradient boosting相当。

## 路径三：MPC-PPO教师-学生解耦框架（新增Branch D）

**文献依据：** Yu等人（2025）提出的MPC-PPO耦合框架 ([Yu et al., 2025](https://arxiv.org/pdf/2504.20815v1))，以及Jiang等人（2026）提出的解耦安全监督框架 ([Jiang et al., 2026](https://www.nature.com/articles/s44333-026-00087-3))。

**核心机制：** Yu等人（2025）的MPC-PPO框架将教师-学生集成分为三个阶段：(1) **预训练阶段**（前2轮）：以90%的高比例将MPC生成的高质量经验注入经验池，快速建立基础策略；(2) **动态替换阶段**（第3轮起）：基于奖励阈值的选择性替换，当 $R_{\text{episode}} < R_{\text{threshold}}$ 时以概率1替换，否则以概率0替换；(3) **重要性权重修正**：通过裁剪重要性采样权重，将经验替换对策略更新的影响限制在合理范围内。

Jiang等人（2026）的解耦安全监督框架则引入了一个**独立的安全引导网络** $G(s, a | \theta^G)$，与奖励优化网络并行训练，通过修改策略梯度更新方向来显式强制安全约束：

$$\nabla_{\theta^\mu} J(\theta^\mu) = \mathbb{E}_{s \sim \rho^\beta}\left[(\nabla_a Q_1(s, \mu(s)) + \nabla_a G(s, \mu(s))) \nabla_{\theta^\mu} \mu(s)\right]$$

**对v1的直接映射：** v1的教师（static-anchor regret-guarded MPC）已经在14/15 seeds上稳定工作，但学生策略（event-threshold）在最终窗口出现制度迁移失败。问题不在于教师质量，而在于**学生策略对教师知识的吸收方式**。Yu等人（2025）的动态替换机制提供了一个关键改进：

- 当前v1的教师集成是**静态的**（固定的监督头权重），而Yu等人（2025）的框架是**动态的**（根据当前策略性能自适应调整教师影响权重）
- 具体地，在v1的训练中引入奖励阈值 $R_{\text{threshold}}$：当当前episode的FW-MAE改善低于阈值时，增大教师经验的替换比例；当改善高于阈值时，减小替换比例，允许学生自主探索
- 这一机制可以防止学生策略在验证窗口过拟合（过度依赖教师），同时在最终窗口保持足够的泛化能力

Jiang等人（2026）的解耦安全网络则提供了另一个改进方向：将能量预算约束从Lagrangian惩罚项（当前v1的固定 $\lambda$）改为一个独立的安全价值函数 $G(s, a)$，通过梯度方向修正而非奖励惩罚来强制约束。这直接解决了Turn 76诊断的Cause 3（软惩罚约束处理中固定 $\lambda$ 的系统性偏差）。

**具体实施步骤（Branch D）：**
1. 在v1的PPO训练循环中，增加一个奖励阈值监控器：每个episode结束后，计算 $R_{\text{episode}}$（相对于static baseline的FW-MAE改善）
2. 若 $R_{\text{episode}} < R_{\text{threshold}}$（建议初始值：0，即任何改善均视为成功），将教师经验替换比例设为0.9；否则设为0.1
3. 同时，将固定 $\lambda$ 替换为独立的安全价值网络 $G(s, a | \theta^G)$，与主策略网络并行训练
4. 在seed41-45上运行n=5 gate实验，评估FW-MAE和约束满足率

**预期效果：** Yu等人（2025）在温室温控任务上，MPC-PPO相比无经验集成基线提升5.46分（96.31 vs 90.85，百分制）。对于v1，动态替换机制预期可以减少学生策略在验证窗口的过拟合，从而改善验证-最终迁移的稳定性。

## 路径四：Whittle指数与RMAB框架（对应理论强化）

**文献依据：** Jonah等人（2026）提出的WIQL-UCB框架 ([Jonah et al., 2026](https://arxiv.org/html/2601.01179))，以及Kongarana等人（2026）的BAFS-CMDP框架 ([Kongarana et al., 2026](https://openreview.net/pdf/d4acb51043380b9161f2877dfd90cf322c2b67c7.pdf))。

**核心机制：** Jonah等人（2026）将传感器调度问题形式化为**Restless Multi-Armed Bandit（RMAB）**，并提出WIQL-UCB策略，通过Q-learning学习Whittle指数来近似最优调度策略。在环境监测应用中（V-C节），WIQL-UCB在不同调度约束M下一致优于RR和AoI基线，且对快速变化的传感器（Category C）分配最高的轮询频率，体现了对系统动态的自适应感知。

Kongarana等人（2026）的BAFS-CMDP框架则将预算感知特征选择形式化为扩展CMDP，其中动作空间 $A_{\text{ext}} = A_{\text{env}} \cup A_{\text{feat}}$ 同时包含环境交互动作和特征选择动作，通过多头Actor架构同时优化两个策略。

**对v1的理论意义：** v1的event-threshold策略本质上是一个**事件感知的RMAB策略**：在事件期间优先激活laser传感器（高信息量、高代价），在非事件期间回退至snow_core（低信息量、低代价）。WIQL-UCB的理论框架表明，最优调度策略应根据传感器的**信息变化率**（而非仅仅是AoI）来分配轮询频率。这为v1的事件感知设计提供了理论支撑，同时也指出了一个改进方向：将事件概率预测 $\hat{z}_t$（TCN输出）直接编码为Whittle指数的状态特征，使调度决策更直接地响应预测的信息增益。

## 综合执行路径（修订版）

基于上述文献，将Turn 85的三分支路径修订为四分支路径，并明确每个分支的文献依据和实施优先级：

**零成本诊断（保持不变，立即执行）：**
- Diag-1：Spearman相关性分析（验证损失动态 vs 最终损失动态），区分协议结构性 vs 策略结构性迁移失败
- Diag-2：seed44制度分析，提取事件密度、SOC分布、教师动作分布

**Branch A（修订）：CAPS在线过滤 + per-start预测器组合**
- 文献依据：Chemingui等人（2025）CAPS框架
- 实施：(1) 用现有9个可部署行的轨迹数据拟合代价Q函数 $Q^c$；(2) 在部署时对每个时间步执行CAPS过滤（若 $Q^c_t + c_{<t} > \kappa$，切换至static）；(3) 在seed41-45上回测
- 成功标准：n=5 gate通过（≥3/5 seeds FW-MAE优于validation_selected_static）
- 失败处理：若n=5 gate失败，立即转Branch B；不进行Branch A扩展

**Branch B（修订）：TREBI轨迹加权 + start-conditioned fallback**
- 文献依据：Lin等人（2023）TREBI框架
- 实施：(1) 过滤 $C(\tau) > 1.20$ 的轨迹；(2) 对满足约束的轨迹按 $\exp(\alpha R)$ 加权；(3) 拟合轻量级条件策略；(4) 在seed41-45上评估
- 成功标准：n=15 gate通过（≥12/15 seeds）
- 失败处理：转Branch C

**Branch D（新增）：MPC-PPO动态替换 + 解耦安全网络**
- 文献依据：Yu等人（2025）MPC-PPO框架；Jiang等人（2026）解耦安全监督
- 实施：(1) 引入奖励阈值动态替换机制；(2) 将固定 $\lambda$ 替换为独立安全价值网络 $G(s, a)$；(3) 重新训练n=5 seeds
- 适用条件：Branch A和Branch B均失败，且Diag-1显示失败为策略结构性（而非协议结构性）
- 成功标准：n=5 gate通过
- 失败处理：转Branch C（声明降级）

**Branch C（保持不变）：声明降级**
- 使用riskcenter n=5（4/5）作为Paper 2初步证据
- 将n=15 gate失败和起点制度迁移风险添加至Paper 2 §7.4 Limitations

## 对Paper 2写作的影响

上述四条路径均可直接转化为Paper 2的技术贡献叙述：

**§4（Forecast-Aware CMDP Framework）** 可引用Kongarana等人（2026）的BAFS-CMDP框架作为形式化基础，将v1的双策略设计（feature selection policy $\pi^u$ + environment interaction policy $\pi^m$）与BAFS-CMDP的多头Actor架构对齐。

**§5（MPC-Teacher Distillation）** 可引用Yu等人（2025）的MPC-PPO框架作为教师-学生集成的直接先例，将v1的static-anchor regret-guarded MPC教师定位为该框架在极地传感器调度场景的特化实例。

**§7.1（Results）** 若Branch A（CAPS）成功，可将结果定位为"约束自适应策略切换在事件感知传感器调度中的首次应用"，引用Chemingui等人（2025）作为方法论先例。

**§7.4（Limitations）** 若Branch D失败，可引用Jiang等人（2026）的解耦安全监督框架作为未来工作方向，指出将固定Lagrangian乘子替换为独立安全价值网络是一个有文献支撑的改进路径。
